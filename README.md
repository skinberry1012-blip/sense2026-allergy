## 연구소를 만든 방식 (새 그림 버전)

1600×900 판(`lab-board`) 위에 **배경 그림 + 캐릭터 + 물건 + 글자·부품을 코드로 얹어요**. 판 전체를 화면 크기에 맞춰 확대·축소해서 태블릿·휴대폰(가로) 모두 같은 모습이에요.

- **좌표**: `data/lab-items.js`의 `[왼쪽, 위, 너비, 높이]`는 1600×900 판 기준 픽셀이에요. 물건 위치(`places.*.points`)를 바꾸려면 여기만 고치면 돼요.
- **문구**: 이야기 대사(`story`), 관찰 말(`observe`), 증상 2개와 예방법(`info`), 카드 대사(`cards.lines`), 대처 단계(`cope`)를 모두 이 파일에서 고쳐요.
- **캐릭터**: 모두 700×504 같은 크기·같은 발끝이라, 같은 높이로 쓰면 키가 맞아요 (`labChar`).
- **부품 함수** (`js/lab.js`): `labBtn`(버튼 A) · `labBubble`(말풍선 B) · `labPanel`(안내판 B) · 스캔 결과 창은 `lab-result`

### 글자 표시 규칙 (`lab-items.js`)
- `[글자]` = 파란 굵은 글씨
- `{{글자}}` = 코랄 굵은 글씨
- `<br>` = 줄바꿈

## 저장 키 (LocalStorage)

| 키 | 내용 |
|---|---|
| `promiseCard.labFound` | 장소별로 찾은 유발물질 `{home, school, ground}` |
| `promiseCard.labComplete` | 연구소를 마쳤는지 |
| `promiseCard.*` (그 밖) | 방패 약속 카드, 5일 챌린지 기록 |
| `appConfig` | 선생님 설정 (수업용/행사용, 게시판 주소, 대기 음악) |
| `appSound` | 소리 켜기/끄기 (기본 켜기) |

증상 카드, 대처 방법 확인, 기억 체크 진행 상태는 앱 메모리에만 있어요. 앱을 다시 켜면 그 부분은 처음부터 해요. `promiseCard.`로 시작하는 기록은 S48 「새로 도전하기」, S39 새로 만들기, 선생님 설정의 「이 기기 기록 지우기」 때 함께 지워져요.

## 확인용 주소

- `?today=2026-11-05` : 날짜를 바꿔서 챌린지 확인
- `?mode=event` : 행사용 모드 (S39부터 시작)
- `?mode=class&board=https://...` : 수업용 + 결과 게시판
- `?sound=off` · `?bgm=off` : 효과음 끄기 · 대기 음악 끄기 (선생님 설정 QR에 자동으로 들어가요)
- `?teacher` : 선생님 설정 열기
